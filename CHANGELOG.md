# 📄 Changelog: Version 1.0.0-alpha

### **Initial Release: The Foundations of LX's Drinks And Food**

Welcome to the first alpha release of **LX's Drinks And Food**! This version establishes the core features and infrastructure for an expanded culinary experience in Minecraft 1.16.5.

---

### ✨ New Features
* **Crops & Produce**
    * Added **Strawberries** and **Grapes** as basic harvesting ingredients.
* **Glassware**
    * Introduced the **Empty Glass Bottle**, a fundamental container for all modded beverages.
* **Beverages**
    * Implemented various **Fruit Juices**.
    * Added early-stage **Fermented Drinks** (Wine and Beer) with initial properties.

### 🛠️ Technical Improvements
* **New Registry System**
    * Migrated to `DeferredRegister` for better performance and cross-mod compatibility.
* **Refactored Mod ID**
    * Officially moved to `lxdf` for a cleaner internal structure.
* **Project Standards**
    * Full integration of the **MIT License** and professional documentation in English.

---

### ⚠️ Alpha Disclaimer
> This is an **Alpha** build. Features, textures, and balancing are currently in development and may change in upcoming updates. Please report any issues on the GitHub repository.
